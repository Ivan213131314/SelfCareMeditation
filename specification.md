# Спецификация проекта: SelfCareMeditation

## 1. Обзор проекта

Мобильное приложение для медитаций с функцией ведения дневника самочувствия. Пользователь выполняет медитативные практики, фиксирует своё эмоциональное состояние и настроение с использованием эмоджи и быстрых ответов. Визуальный стиль ориентирован на приложение CALM Self-Care.

### Основные цели

- Предоставить пользователю пространство для медитативных практик.
- Дать возможность отслеживать своё самочувствие и настроение.

### Границы проекта (Scope)

**Входит в scope:**

- Каталог релаксирующих практик и информационных материалов.
- Раздел для выполнения медитаций.
- Дневник самочувствия с записями о настроении.
- Использование эмоджи при заполнении дневника.
- Короткие шорткат-ответы для быстрого ввода.
- Три вкладки с возможностью переключения через нижнее меню.
- Переходы между вкладками (каталог → медитация → дневник).
