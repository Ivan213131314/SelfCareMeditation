# Модуль: Journal

## Назначение

Ведение дневника самочувствия с возможностью фиксировать эмоциональное состояние и настроение пользователя.

## Зона ответственности

- Создание записей о самочувствии
- Хранение истории записей
- Использование эмоджи для выражения настроения
- Предоставление быстрых ответов (шорткатов) для упрощённого ввода
- Просмотр ранее созданных записей

## Основные операции

- Создание новой записи
- Выбор эмоджи для записи
- Использование шорткат-ответа
- Добавление текстового комментария
- Получение списка записей
- Просмотр отдельной записи

## Данные

- **Запись дневника** — сущность с датой, выбранным эмоджи, текстом и опциональными шорткатами
- **Эмоджи** — предопределённый набор символов для обозначения настроения
- **Шорткат** — короткий стандартный ответ для быстрого заполнения

## Внешние взаимодействия

- Модуль **Meditation** — возможность создания записи после завершения практики
- Модуль **Auth** — привязка записей к конкретному пользователю
- Внешнее хранилище данных — сохранение и получение записей

## Ограничения

- Записи привязаны к авторизованному пользователю
- Пользователь может редактировать только свои записи
- Эмоджи и шорткаты — предопределённый набор, не редактируемый пользователем
