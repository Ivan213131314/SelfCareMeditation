# Модуль: Meditation

## Назначение

Обеспечение выполнения медитативных практик пользователем.

## Зона ответственности

- Управление процессом выполнения медитации
- Воспроизведение контента практики
- Отслеживание состояния сессии (активна, на паузе, завершена)
- Фиксация факта выполнения практики

## Основные операции

- Запуск сессии медитации
- Приостановка сессии
- Возобновление сессии
- Завершение сессии
- Отслеживание прогресса выполнения

## Данные

- **Сессия медитации** — текущее состояние выполнения практики (выбранная практика, прогресс, статус)
- **Прогресс** — информация о времени выполнения и достигнутом этапе

## Внешние взаимодействия

- Модуль **Catalog** — получение выбранной практики для выполнения
- Модуль **Journal** — возможность перехода к записи самочувствия после завершения
- Внешнее хранилище данных — получение медиа-контента практики

## Ограничения

- Одновременно может выполняться только одна сессия
- Сессия привязана к конкретной практике
- При выходе из сессии прогресс не сохраняется для продолжения
