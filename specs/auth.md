# Модуль: Auth

## Назначение

Управление идентификацией и авторизацией пользователя в приложении.

## Зона ответственности

- Регистрация новых пользователей
- Вход в приложение
- Выход из приложения
- Определение текущего состояния авторизации
- Хранение данных профиля пользователя

## Основные операции

- Регистрация пользователя
- Аутентификация (вход)
- Выход из аккаунта
- Проверка состояния сессии
- Получение данных текущего пользователя

## Данные

- **Пользователь** — сущность с идентификатором и базовой информацией профиля
- **Сессия авторизации** — текущее состояние входа (авторизован / не авторизован)

## Внешние взаимодействия

- Модуль **Journal** — предоставление идентификатора пользователя для привязки записей
- Внешний сервис аутентификации — выполнение операций регистрации, входа и выхода

## Ограничения

- Без авторизации доступ к персональным данным невозможен
- Одновременно активна только одна сессия пользователя
- Данные авторизации не хранятся в открытом виде
