# Модуль: Catalog

## Назначение

Предоставление пользователю каталога релаксирующих практик и информационных материалов для выбора и просмотра.

## Зона ответственности

- Хранение и предоставление списка доступных практик
- Категоризация практик по типам
- Отображение информации о каждой практике
- Выбор практики для выполнения

## Основные операции

- Получение списка практик
- Получение детальной информации о практике
- Фильтрация практик по категориям

## Данные

- **Практика** — сущность с названием, описанием, длительностью, категорией и медиа-контентом
- **Категория** — группировка практик по типу (например: дыхание, релаксация, сон)

## Внешние взаимодействия

- Модуль **Meditation** — передача выбранной практики для выполнения
- Внешнее хранилище данных — получение списка практик и медиа-контента

## Ограничения

- Практики доступны только для чтения
- Пользователь не может создавать или редактировать практики
- Каталог должен быть доступен без активного выполнения медитации
